## Regenerating

Everything below `after/` and both text files come from a local production
build with a server on :3000.

```
npm run build
npm run serve          # in another shell — it kills whatever holds the port

npm run check:hero     # captures docs/phase3/current, compares against after/
npm run check:preloader
npm run check:contrast
npm run check:vitals

npm run lighthouse -- https://www.zubyr.dev/ prod
npm run lighthouse -- http://localhost:3000/ local
```

`lighthouse` is fetched by `npx` for the run and is not a dependency. It is what
PLAN §0.5's "Edge DevTools -> Lighthouse panel" asks for, driven from the command
line; PageSpeed Insights against production is still the authoritative number
when its API quota allows.

The hero capture suppresses the intro overlay by pre-setting its session
cookie, using the name exported from `lib/intro.mjs` — the same switch a
reader's second page view flips. `check-contrast` does the same, for
determinism. `check-preloader` is the one that deliberately runs both ways.
